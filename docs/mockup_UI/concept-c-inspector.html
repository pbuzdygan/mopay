Concept C · Inspector three-pane workspace, no modes, command palette
All concepts

Inspector – one place for everything about the selection

  • Three panes: navigation rail (icon + label, §37), the grid, and a persistent inspector. The selection drives the inspector: cell → value, tag and entry facts; group → name, subtotal, entries; nothing → year summary.
  • BetterNo Tags mode. Tag colour and note are edited in the inspector for the focused cell at any time. Same data model (none/grey/green/orange/red + text).
  • BetterNo Arrange mode on desktop. A grip appears on row hover for drag-and-drop; keyboard alternative Alt+↑/↓. Touch devices keep the explicit Arrange mode.
  • BetterEntry facts next to the value: average, highest month, same month last year (data the Reports view already loads) – helps decide if a number is right while entering it.
  • Auto-save on blur/Enter with a visible "Saved" indicator replaces silent saving (§16 feedback). Status bar shows selection sum, sync state and version.
  • Density: 32px rows, 12px tabular numbers – the whole year with Sum/Avg fits a 1440px screen with the inspector open (§35).

Multi-select instead of Remove mode

  • Row checkboxes appear on hover; Shift-click selects a range. The inspector switches to a bulk panel: count, combined sum, Move to group, Remove.
  • BetterMove to group for several entries at once – today this is one entry at a time in details. Uses the existing entry update call per item.
  • Removal still requires explicit confirmation with a specific label.

Command palette (Ctrl/⌘ K)

  • Every action in MOPAY is reachable by name: create entry/group, jump to section, switch year, year operations, import/export, settings, lock, theme (§22 command palette).
  • Searching also matches entries and goals; choosing one selects it and opens the inspector.
  • Additive: buttons and menus stay, the palette is a shortcut. / still focuses table search.

Reports – summary → trend → details (§21)

  • KPI row: income, expenses, net result, savings rate with change vs previous year.
  • One combined chart: income and expense bars per month with the net result as a line – replaces 12 mini cards. Clicking a month selects it and the inspector shows that month's breakdown.
  • "Where money went" uses horizontal bars instead of a donut – easier to compare and label (§21 visualise only when it helps).
  • Top entries and predictability stay, presented as compact tables.
