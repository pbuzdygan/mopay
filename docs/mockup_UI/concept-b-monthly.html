Concept B · Monthly top navigation + month-first workflow
All concepts

Month view – the routine task first

  • Observation: the recurring job in MOPAY is "enter this month's bills and salary, then check the balance". Today it happens in a 12-column grid where the current month is one narrow column among twelve (§30 function before style).
  • BetterMonth view (default for Expenses/Incomes): one row per entry with previous month for reference, an always-editable amount field and change vs previous month. Writes use the same per-month PATCH /entries/:id as the grid.
  • BetterEmpty cells suggest last month's value (Use 300,00) and Fill empty from September fills all blanks in one step – client-side only, no API change. Optional; can be dropped without affecting the rest.
  • Side panel: month balance (income − expenses), how many entries are filled, things needing attention (tag notes, unusual changes, empty entries) and a 12-month strip that doubles as month navigation.
  • Tags show their note under the entry name, so information is readable without hovering (§18 – not only colour, not only tooltip).
  • Top navigation (§11): 4 sections as tabs, global search with /, year selector, menu (Year operations, Import, Export, Settings), lock and theme. All existing actions remain; Arrange / Remove / Tags live in the ⋯ menu next to New.

Year view – kept, simplified

  • The full 12-month grid stays one click away (Month | Year toggle, remembered per user) for annual review, imports and bulk corrections.
  • Month headers are buttons: clicking Oct opens the month view for October.
  • Group rows become light section headings with subtotals; the footer adds net result per month (income − expenses) on the Expenses tab, data already available to Reports.
  • Tags render as a coloured underline under the value – no cell background change, number stays readable.

Mobile – designed, not shrunk (§17)

  • The month view is naturally a list, so phones no longer need a horizontally scrolling 14-column table.
  • Bottom tab bar for the 4 sections plus More (Year operations, Import, Export, Settings, Lock, theme, version) – 44px+ touch targets.
  • Tapping an entry opens a bottom sheet: large numeric field (16px+ prevents iOS zoom, existing requirement), quick values (last month, average), tag colour and note, link to entry details. Replaces separate cell edit, Tag mode and context panel on touch.
