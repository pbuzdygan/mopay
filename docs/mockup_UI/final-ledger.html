All concepts

Overview – the start page (former Reports)

  • Reports becomes Overview, is first in the sidebar and opens after unlock: a dashboard first, then you move to Expenses, Incomes or Savings to work.
  • Built only from what Reports shows today, re-ordered as summary → trend → details (§21): 1. income, expenses, net result and saved in goals, each compared with the previous year; 2. month by month with best and weakest month; 3. where money went (groups + top 5 entries) and savings overview; 4. predictability.
  • Simplifications: the donut becomes horizontal bars sharing one scale with the top entries list (easier to read and compare); best/weakest are labelled in text, not only by colour; the current month is outlined; months without data are dashed.
  • Same calculations as today (reports/analytics.ts): stability = 100 − coefficient of variation, best/weakest by monthly net result. Year-over-year percentages in the mockup are illustrative.
  • Clicking a month opens Expenses with that month's column selected; Open savings goes to Savings. Search is hidden here, as it is disabled on Reports today.

Expenses – base layout (Concept A)

  • Sidebar: brand, working year, Overview first, then Expenses, Incomes, Savings with yearly totals, then Settings, Lock session, theme and version. Year operations, Import and Export moved into the Settings page (Concept D), so the sidebar has fewer equal-level items (§37).
  • Compact header: title + count, search (/, Ctrl/Cmd+K), Edit menu (Arrange, Remove) and the primary New entry split button (with New group).
  • Summary strip, sticky header / name column / totals, quiet group rows with subtotals, tags as a coloured bar plus a note corner.
  • Clicking a value selects the cell and opens the inspector. Double-click, Enter or typing still edits in place, arrows move the selection – fast entry stays possible without the panel.

Cell selected – inspector (Concept C), requested order

  • 1. Value of the selected month with quick fill (previous month, average, clear).
  • 2. Entry details: name, group, comment. 3. Tag: colour + note for this month. 4. Entry: 12-month chart with the average line, then Sum, Average, vs previous month, same month previous year.
  • The panel replaces three separate things: the details panel, Tag mode with its popover, and per-cell tooltips. Remove entry stays in the footer with a confirmation step.
  • The panel works like Concept A's drawer: it slides over the right part of the table and the layout underneath never changes – no sidebar collapse, no grid re-flow when a cell is selected. It is non-modal (no dimming), so clicking another visible cell just updates the panel. The selected row stays highlighted with an accent edge so the context is clear even when the selected month is under the panel. Esc or ✕ closes it.
  • Selecting a group row shows group details in the same panel (rename, add entry to group, arrange, remove group); selecting an entry name shows sections 2 and 4 only. Not drawn separately.
  • Changes save on blur/Enter; the footer shows "Saved hh:mm" or an inline error.

Edit menu

  • Holds the remaining modes: Arrange (drag handles for entries and groups) and Remove (bulk selection). Tag mode is no longer needed on desktop because tagging lives in the inspector.
  • Shortcuts are shown next to items; the menu is keyboard navigable.

Remove mode (Concept A)

  • Mode banner explains the state; checkbox column for entries and whole groups; floating bulk bar with a specific action label and a confirmation dialog after it.
  • Arrange mode uses the same banner and column with drag handles.

Savings – list + detail (Concept D logic, Concept A styling)

  • Goals on the left with progress; selected goal on the right: balance vs target, remaining, contributions, withdrawals.
  • Quick add form inside the goal: note, amount and type (Contribution / Temporary withdrawal – stored as a negative item, same model as today).
  • Item edit/delete on row hover; goal edit in the header, delete in the ⋯ menu. Goals without target show "No target".

Settings page (Concept D approach)

  • One page with in-page navigation replaces the hamburger menu and four modals: Display, Security, Years, Import & export, About, Danger zone.
  • Year deletion keeps Concept A's safeguards: checklist with entry counts, working year protected, export reminder, typed confirmation.
  • New: theme option System; optional "copy entries and groups" when creating a year.
  • Demo mode: Years and Import show a read-only explanation instead of hidden menu items.

Mobile (Concept B), aligned with the final design

  • Bottom tab bar: Overview, Expenses, Incomes, Savings, More. Below 960 px Expenses and Incomes become a month list with month stepper, monthly summary and bottom tab bar; no horizontally scrolling grid.
  • Tapping an entry opens a bottom sheet with the same order as the desktop inspector: Value, Entry details (expandable), Tag, Entry facts.
  • Savings uses the list → detail flow from desktop; More opens Settings, theme and Lock.
  • Touch targets ≥ 44 px, inputs 16 px to avoid iOS zoom. The desktop year grid remains available in landscape/tablet widths.
