# AGENTS

Default instruction for AI agents working in this repository:

- Follow the operating rules in `docs/agent_rules.md`.
- Use those rules for repository exploration, code edits, communication, and verification.
- Prefer minimal reads, targeted patches, and narrow verification.
- If repository-specific instructions conflict with the generic rules, repository-specific instructions take priority.

Recommended startup behavior for each task:

1. Read `AGENTS.md`.
2. Load `docs/agent_rules.md`.
3. Apply those rules by default unless the user explicitly requests a different workflow.
